# 医院运营指标口径说明

本项目将医院管理层常用问题拆成可查询的结构化指标。指标用于运营分析，不替代医院正式统计报表。

## 门诊量

门诊量 = `outpatient_visits` 表中符合时间条件的 `visit_id` 数量。

管理意义：反映门诊服务量、排班压力和患者流量变化。

## 科室收入

科室收入 = `billing_records.amount` 按 `department_id` 汇总。

管理意义：反映科室服务量和费用结构，但不能单独作为绩效评价依据，应结合病种、成本和质量安全指标。

## 药品收入占比

药品收入占比 = `item_type='药品'` 的金额 / 总收费金额。

管理意义：用于内部合理用药和费用结构监测。注意：公开政策近年来更强调医疗质量、安全、效率和满意度等综合绩效，不宜把药品收入占比作为单一评价标准。

## 床位使用率

床位使用率 = `occupied_beds / open_beds * 100%`。

管理意义：反映住院资源使用压力。本 Demo 将 90% 作为床位紧张预警阈值，用于演示异常提示。

## 平均住院日

平均住院日 = 已出院患者住院天数平均值。

管理意义：反映诊疗效率、床位周转和流程管理水平，需要结合病种复杂度和医疗质量共同判断。

## 手术量

手术量 = `surgery_records` 表中符合时间条件的 `surgery_id` 数量。

管理意义：反映手术科室工作量，可按手术级别进一步分析技术难度和资源占用。

## 耗材收入占比

耗材收入占比 = `item_type='耗材'` 的金额 / 总收费金额。

管理意义：用于观察费用结构和高值耗材管理风险。真实医院应结合病种、手术级别、医保支付规则和耗材准入制度进一步分析。

## 医疗服务收入占比

本 Demo 将治疗、手术、床位、挂号归入医疗服务收入，用于演示收入结构优化分析。

医疗服务收入占比 = 治疗、手术、床位、挂号收入合计 / 总收费金额。

注意：真实医院统计口径可能与本 Demo 不完全一致，应以院内财务和绩效口径为准。

## 病床周转次数

病床周转次数 = 出院人次 / 平均开放床位数。

管理意义：反映床位资源周转效率，需要和床位使用率、平均住院日、医疗质量指标一起看。
