# DRG/DIP 医保支付与医院运营管理

DRG/DIP 支付改革会改变医院运营管理的关注点。医院不能只看收入和工作量，还要关注病案首页质量、医保结算清单、费用结构、病种成本、临床路径、医疗质量和绩效分配。

## 常见管理问题

- 哪些科室的药品、耗材、检查费用占比偏高？
- 哪些病种可能存在费用超支风险？
- 病案首页和医保结算清单是否存在编码、完整性和一致性问题？
- 科室绩效是否只按收入分配，是否纳入病种难度、质量安全和成本控制？
- 是否存在低风险病例费用异常、住院日过长或检查治疗结构异常？

## 本 Demo 可支持的问题

- 药占比、耗材占比、检查检验收入占比。
- 平均住院日、床位使用率、床位周转次数。
- 科室收入、住院人数、手术量和手术级别分布。

## 暂未接入的数据

真实 DRG/DIP 管理还需要病案首页、医保结算清单、病种分组、医保支付标准、病例组合指数、费用消耗指数、时间消耗指数等数据。当前 Demo 没有这些真实数据，因此只做管理口径解释和模拟运营指标分析。
