# 医保控费风险观察说明

医保控费不是简单压低费用，而是在保证医疗质量和患者安全的前提下，关注费用结构、住院效率、病种成本和医保支付规则之间的匹配关系。

## 本项目观察的风险

- 药占比偏高：提示需结合病种结构、合理用药和临床路径复核。
- 耗材占比偏高：提示需关注高值耗材使用、手术类型和耗材准入。
- 平均住院日偏长：提示需关注出入院流程、病情复杂度和床位周转。
- 模拟 DRG/DIP 亏损：病例总费用高于模拟支付金额时，提示经营和费用结构风险。
- 高风险病例：同时命中费用超支、住院日偏长或高风险病组亏损等规则。

## 与 DRG/DIP 的关系

DRG/DIP 支付会让医院不能只看收入和工作量，还要看病组成本、费用消耗、时间消耗、病案质量和医保支付标准。本项目用模拟病组和模拟支付金额展示这种管理思路。

## 当前边界

当前系统只做“医保控费观察”，不做正式 DRG/DIP 入组、结算预测或医保审核判断。真实落地需要接入病案首页、医保结算清单、诊断编码、手术编码、本地分组规则、支付标准和病例成本。

## 管理建议

当科室风险分较高时，建议由运营办或医保办牵头，联合病案室和临床科室复核病例费用、住院日、费用结构和编码质量。系统输出应作为管理复核线索，不应直接作为处罚或诊疗决策依据。
