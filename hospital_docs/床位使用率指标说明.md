# 床位使用率指标说明

床位使用率用于衡量开放床位的实际占用情况。

## 计算方式

床位使用率 = 占用床位数 / 开放床位数 * 100%。

在本项目中，对应字段为：

- 开放床位数：`bed_daily_stats.open_beds`
- 占用床位数：`bed_daily_stats.occupied_beds`

## 管理意义

- 使用率较高：提示住院资源紧张、出入院流程压力较大。
- 使用率较低：可能提示床位资源配置、科室需求或患者流量不足。
- 连续高位运行：需要关注医疗安全、护理负荷和床位周转。

## Demo 阈值

本项目将 90% 作为“床位紧张”的演示阈值。真实医院应结合医院等级、科室属性、季节性和区域医疗资源设置阈值。
