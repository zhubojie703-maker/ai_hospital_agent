# 公立医院绩效管理参考

本知识库参考公开政策资料整理，供项目 Demo 进行管理解释使用。

## 公开依据

- 国家卫生健康委发布的《三级公立医院绩效监测操作手册（2025版）》通知说明，三级公立医院绩效监测强调医疗质量、运营效率、持续发展和满意度等维度。
- 国务院办公厅《关于加强三级公立医院绩效考核工作的意见》提出，通过绩效考核推动三级公立医院在发展方式、管理模式和资源配置等方面转变。

## 项目中的使用方式

本项目不复刻完整官方考核体系，而是选取医院运营管理层常问的指标做 Demo：

- 门诊量：用于观察服务量和患者流量。
- 科室收入：用于观察经营结构。
- 床位使用率：用于观察住院资源压力。
- 药品收入占比：用于观察费用结构和合理用药风险。
- 平均住院日：用于观察诊疗效率和床位周转。
- 手术量：用于观察手术科室工作负荷。

## 注意事项

绩效管理不能只看收入或工作量，还要结合医疗质量、成本控制、患者体验、学科发展和医务人员负担等因素。
