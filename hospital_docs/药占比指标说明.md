# 药品收入占比指标说明

药品收入占比用于观察药品费用在总费用中的比例。

## 计算方式

药品收入占比 = 药品收入 / 总收入 * 100%。

在本项目中：

- 药品收入：`billing_records.item_type = '药品'` 的 `amount` 汇总。
- 总收入：同一时间范围内 `billing_records.amount` 总和。

## 管理意义

该指标可以帮助医院观察费用结构和合理用药风险，但不能单独判断科室管理好坏。药品占比偏高时，应结合病种结构、收治患者严重程度、临床路径和医保政策进一步分析。

## Demo 阈值

本项目使用 30% 作为演示预警阈值，只用于说明系统可以做规则提示，不代表所有医院的统一考核标准。
