# AI 医管后台 UI 升级过程表

| 阶段 | 参考界面特征 | 本项目改动 | 效果 |
|---|---|---|---|
| 1. 视觉框架 | 左侧导航、深色医疗后台、绿色状态色 | 重构为侧边栏多页面后台，统一深色主题和卡片样式 | 从单页 Demo 变成可展示的医管驾驶舱 |
| 2. 内容驾驶舱 | 顶部 KPI 卡片、实时状态、关键发现 | 新增门诊量、收入、床位使用率、药占比、手术量、住院人数 KPI | 管理层进入页面即可看到核心运营状态 |
| 3. 图表分析 | 趋势图、分布图、风险图、结构图 | 新增门诊/收入趋势、收入结构、床位风险、手术级别、科室绩效图 | 数据从表格结果升级为可解释的运营图谱 |
| 4. AI 助手侧栏 | 右侧 AI 助手给出结论和下一步行动 | 新增关键发现、风险提示、建议动作和智能问答解释区 | 页面不只展示数据，还能辅助决策 |
| 5. 管理表格 | 患者/样本/用户管理表格 | 新增科室绩效明细表、床位风险表、问答结果中文列名 | 便于筛查、比较和面试演示 |
| 6. 项目包装 | 专业产品级后台而不是脚本输出 | 新增改动记录页和文档化过程表 | 方便写简历、讲项目升级路径 |
| 7. 前端骨架化 | 先定设计风格、技术方案、模块边界、组件复用规则和样式 token | 新增 `UI_TOKENS`、`PAGE_REGISTRY`、`render_current_page` 和 `docs/frontend_skeleton.md` | 后续新增页面时更容易保持统一医管后台风格 |
| 8. 医保控费观察 | 风险评分、科室排行、病组盈亏和边界说明 | 新增模拟 DRG/DIP 数据、科室风险评分和医保控费观察页 | 从运营看板升级为能解释控费风险的产品原型 |

## 当前页面结构

| 页面 | 主要内容 |
|---|---|
| 运营总览 | KPI 卡片、门诊/收入趋势、收入结构、床位风险、科室绩效明细、AI 医管助手 |
| 浮窗问答 | 页面内 AI 小浮窗，输入问题后再展开表格、图表和结论 |
| 智能问答 | 示例问题、自然语言查询、结果表格、自动图表、分析结论、RAG 指标解释 |
| 趋势分析 | 近 60 天门诊与收入趋势、收入结构占比、床位排名、手术级别分布 |
| 科室绩效 | 收入与门诊量散点图、药品/耗材占比、科室运营明细 |
| 医保控费观察 | 模拟 DRG/DIP 病组、科室风险排行、病组盈亏和边界说明 |
| 运营简报 | 自动生成月度运营报告和报告解读 |
| 医管知识库 | 指标口径、医保控费、DRG/DIP、绩效考核等知识文档 |
| 改动记录 | 本次 UI 和内容升级过程表 |

## Vibe 前端骨架落地

| 骨架项 | 本项目落地 |
|---|---|
| 整体设计风格 | 深色医管后台、绿色状态色、高信息密度、8px 卡片圆角 |
| 技术方案 | Streamlit + Plotly + pandas + SQLite，保留现有栈不引入额外前端框架 |
| 模块边界 | 页面由 `PAGE_REGISTRY` 注册，渲染由 `render_current_page` 分发 |
| 组件复用 | 统一使用 `render_header`、`section_title`、`render_metric`、`render_assistant_panel` 和 `style_fig` |
| 样式系统 | 颜色、圆角、图表色板集中在 `UI_TOKENS` 和 `CHART_COLORS` |
| 新增风控表达 | “医保控费观察”只做模拟风险观察，不做正式 DRG/DIP 结算预测 |
| 实施计划 | 详见 `docs/frontend_skeleton.md` |
